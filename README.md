# Tic Tac Toe Game 🎮

A simple Tic Tac Toe game in Python where you play against the computer.

## How to Play
Enter a number 1-9 to place your X:

1 | 2 | 3 
4 | 5 | 6
7 | 8 | 9


Computer plays as O. First to get 3 in a row wins!

## Run it
python tic_tac_toe.py
